## 🧭 我信这几条

1. **内核不变，工具可换** — 方法论是资产，工具是耗材
2. **先定骨架再填肉** — 命名、编号、层级、双链，四件事定死再动笔
3. **不碰撞不落地** — 任何结论都要过「大佬怎么做 / 行业往哪走 / 适不适合我」三关
4. **事实必须带来源** — 说不清出处的，标「待核」，不装懂
